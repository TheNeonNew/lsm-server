● Установите модули проекта командой:
  ```bash
  bun install
  ```

2. Запуск сервера

● Для запуска в режиме разработки с автоматической перезагрузкой:
  ```bash
  bun run dev
  ```
● Для запуска в режиме production:
  ```bash
  bun run start
  ```

3. Миграции базы данных

● Перед запуском сервера убедитесь, что выполнены миграции:
  ```bash
  bun run migrate
  ```

4. Тестирование

● Запуск всех тестов проекта:
  ```bash
  bun run test
  ```
● Запуск тестов в режиме наблюдения:
  ```bash
  bun run test:watch
  ```

5. Примечания

● Серверная часть использует TypeScript и Express.
● Для работы проекта требуется Node-подобная среда Bun.
● Если на системе нет Bun, установите её согласно официальной документации.
